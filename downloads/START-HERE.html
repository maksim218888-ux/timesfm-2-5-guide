TimesFM 2.5: начните с проверяемого прогноза

Этот набор повторяет маршрут из гайда: фиксирует версию и лицензию, запускает point + q10/q50/q90, сравнивает результат с seasonal-naive и сохраняет rolling backtest.

Граница: код и веса TimesFM 2.5 доступны по Apache-2.0 согласно уведомлению официального репозитория. Перед коммерческим внедрением проверьте лицензию и security-требования. Не заменяйте checkpoint скачанными весами TimesFM-3: у них отдельный некоммерческий режим.

Порядок запуска

Создайте окружение.
python -m venv .venv, затем установите зависимости из requirements-cpu.txt.
Проверьте готовый пример.
Из каталога распакованного набора запустите python timesfm_workflow.py --data noaa_co2_snapshot.csv --folds 5. Скрипт сохранит метрики и артефакты в output/.
Подставьте свой ряд.
Скопируйте структуру business_series.csv, не меняя смысл timestamp, series_id и target.
Сравните с простым правилом.
Не принимайте прогноз, пока он не прошёл holdout и rolling-проверки на тех же датах, что и baseline.
Подключайте агента безопасно.
Используйте forecast_contract.yaml и agent_tool_contract.json. Forecast возвращает рекомендацию, но не выполняет действие.
