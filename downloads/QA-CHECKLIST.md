# Проверка перед передачей владельцу

## Данные
- [ ] Выбран один ряд.
- [ ] Дата распознана.
- [ ] Цель числовая.
- [ ] Нет необъяснённых дублей и пропусков.
- [ ] Шаг времени стабилен.
- [ ] Есть несколько повторяющихся циклов.
- [ ] Резкие изменения в истории описаны.

## Проверка прогноза
- [ ] Будущие значения не попали во вход.
- [ ] TimesFM и простое правило проверены на одинаковых датах.
- [ ] Проведено несколько последовательных проверок на прошлом.
- [ ] Показаны ошибка и ширина диапазона.
- [ ] Честно указано, если простое правило лучше.

## Результаты
- [ ] Созданы все CSV, JSON, PNG и `DECISION-MEMO.md`.
- [ ] Записаны версии, model ID, revision и hash входного CSV.
- [ ] Вывод написан простым русским языком.
- [ ] Прогноз назван дополнительным сигналом, а не гарантией.
- [ ] Никакое бизнес-действие не выполнено автоматически.
